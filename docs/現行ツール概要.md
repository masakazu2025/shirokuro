# Shirokuro
※本ポートフォリオの元となる、社内で運用中のツールの説明を行う

## 目的
POSの結合テスト業務における、エビデンス(取引データ・画像・ログ)の採取・閲覧・整理を効率化する社内ツール。

## 課題(開発前)
- 評価者によるエビデンスの採取漏れ
- 採取ルール(提出用フォルダの命名等)の不統一。メンバー交代のたびに指導が必要だった
- 取引詳細閲覧に使うExcelマクロが重く、読み込み中に落ちることがあった
- 採取(バッチファイルでIP・日付・取引番号を指定して取得)と、閲覧・比較(Excelマクロ)が別々の手作業に分かれていた

## 技術スタック
- バックエンド: Python / Flask / Jinja2 / pandas / openpyxl / xlwings
- フロントエンド: Bootstrap / JavaScript
- 社内の利用許可ソフトウェア一覧の範囲内で選定

## 開発・運用期間
- 開発: 約1.5〜2年(実務の合間に調査・実験・リファクタリングを重ねながら)
- 運用: 長期プロジェクトで約1年

## 主な機能

### 端末監視・自動採取
指定したIPアドレスの端末を監視し、新たな取引データが作成されると、付随するログやスクリーンショットも含めて自動的に採取する。ポートフォリオでは、ファイルの作成を伴うので割愛。

### 取引閲覧・整形
採取した取引データ(テキスト/csv/xml等)を、項目ごとに切り替えて閲覧する。値の羅列だけで意味が取れないデータは、設計書(Excel)やcsv設定ファイルから日本語ラベルを読み込んで整形表示する機能も備える。

### 取引・画像データの整理
採取した取引・画像データを提出用に整理する。Excelのテスト仕様書をインポートし、機能名・シート名を利用することで、整理作業を簡潔にする。

### その他機能
#### ログ採取
取引が行われた時間範囲を特定し、ログを切り出して保存する。

#### 画像閲覧
画面遷移確認等、画像閲覧に特化した確認をサポートするための機能。整理機能も実装（リネーム・保存等）。

#### 取引比較
既存のExcel比較マクロにファイルを渡して、Excelを開かずに比較実行。マクロも軽量化を行う。

#### 不具合資料採取
ログや設定ファイルなど、調査に必要なファイルを一括取得。取得内容は設定で追加・削除可能。

#### 設定画面
各機能の設定をUIから可能とした。

## 成果
- 約2時間/人日の作業コストを削減
- 閲覧・比較のコストが下がったことで、閲覧・比較の実施回数自体が増加。効率化に加え、業務の質の向上にも寄与
